# Tracker Owl States

Набор состояний совы-маскота для Tracker.

Общий визуальный образ: коричневая сова в чёрном худи **Antihype** с подписью **I BALL WAS RAWT**, белый фон, комикс/стикерная стилистика.

## Файлы и сценарии

| Файл | Сценарий | Что изображено | Текст на картинке |
|---|---|---|---|
| `owl_pending.png` | На сегодня есть привычки/действия без отметки | Злая сова указывает на пользователя и требует закончить отметки | **«ЭЙ, БЛЯТЬ, ОТМЕТЬ ПРИВЫЧКУ!»** |
| `owl_failed.png` | Конкретная привычка/задача провалена | Недовольная сова стоит, уперев крылья в бока | **«У ТЕБЯ ЕСТЬ ПОРОХ ИЛИ КАК?»** |
| `owl_all_done.png` | Всё на сегодня отмечено | Довольная сова развалилась отдыхать с кружкой | На кружке: **«НУ ВОТ.»**; основная подпись: **«МОЖЕШЬ ЖИТЬ.»** |
| `owl_insight.png` | Tracker нашёл интересный инсайт/закономерность | Сова-нёрд в очках читает книгу с графиком | **«ТАК. А ВОТ ЭТО УЖЕ ИНТЕРЕСНО.»**; на книге: **INSIGHTS** |
| `owl_many_misses.png` | Накопилось много пропусков | Супер-недовольная, уставшая сова с пролитой кружкой | **«НУ ТЫ СЕРЬЁЗНО? СТОЛЬКО ПРОПУСКОВ...»**; на кружке: **«ОПЯТЬ ПРОПУСТИЛ»** |
| `owl_record.png` | Новый рекорд или заметный стрик | Максимально довольная/охуевшая сова празднует с поднятыми крыльями | **«НОВЫЙ РЕКОРД!»** |

## Предлагаемые ключи состояний

```text
pending
failed
all_done
insight
many_misses
record
```

## Логика использования

- `pending` — обычное напоминание, когда есть неотмеченные пункты.
- `failed` — отдельный провал конкретной привычки/задачи.
- `all_done` — состояние успешного завершения дня.
- `insight` — карточка нового статистического наблюдения / корреляции.
- `many_misses` — усиленное негативное состояние при серии или большом количестве пропусков.
- `record` — новый личный рекорд; также подходит для важных стриков.

Не использовать `many_misses` вместо обычного `failed`: эта сова должна появляться редко, чтобы состояние ощущалось сильнее.
